A clean, modern directory theme for mental health professionals in the Raleigh/Triangle area.

== Description ==

My Health Hub is a WordPress theme designed specifically for directories of mental health professionals. Built with performance and user experience in mind, it provides a fast, mobile-first interface for connecting clients with therapists, counselors, and life coaches.

**Features:**

* **Mobile-First Design** - Fully responsive layout optimized for all devices
* **Custom Templates** - Specialized templates for Get Matched, Claim Listing, and Testimonial forms
* **SEO Optimized** - Built-in structured data and meta tags for better search visibility
* **Performance Focused** - Lazy loading, optimized assets, and minimal dependencies
* **Accessibility Ready** - WCAG 2.1 AA compliant markup and interactions
* **Customizer Support** - Easy customization through WordPress Customizer

**Templates Included:**

* Home page with hero section and search
* Get Matched form template
* Claim Listing form template
* Submit Testimonial form template
* 404 error page
* Search results page
* GeoDirectory integration templates

**Recommended Plugins:**

* My Health Hub Core - Required for lead/claim/testimonial functionality
* GeoDirectory - For directory listing management

== Installation ==

1. Upload the theme files to `/wp-content/themes/myhealthhub/`
2. Activate the theme through the 'Appearance' > 'Themes' menu in WordPress
3. Install and activate recommended plugins
4. Configure settings in 'Appearance' > 'Customize'

== Frequently Asked Questions ==

= Does this theme work without GeoDirectory? =

Yes, the theme works as a standard WordPress theme. However, for full directory functionality, GeoDirectory is recommended.

= Is this theme translation-ready? =

Yes, the theme is fully internationalized and ready for translation.

= Can I customize the colors? =

Color customization can be done through the Customizer or by modifying the CSS variables in style.css.
